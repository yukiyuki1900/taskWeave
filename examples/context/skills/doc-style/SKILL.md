# 文档交付方法

1. 先查看交接包，核对上游节点、attempt、产物路径和 hash；再读取所需需求、源码与测试文件。
2. 编写 README.md，包含 `## 使用说明`、`## 验证结果` 和 `## 限制`。示例必须与实际导出、参数和返回值一致。
3. 验证结果只引用已完成的工具观测或明确标明来自上游已验收摘要；没有执行证据时写“未执行”，不编造通过结果。
4. 当上下文变长时使用 record_summary 记录事实、决策、约束与未决问题，并引用 goal、产物 hash 或此前的工具调用 ID。
5. 完成后说明交付文件与仍需人工核对的内容，保留人工验收门禁。

本 Skill 不新增工具、命令或权限。上游交接产物是本节点的只读输入，发现需要修改时报告原因，由用户返工对应节点。
