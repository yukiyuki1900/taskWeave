# TaskWeave v0.5.0-alpha.1

v0.5 将本地 CLI 的执行记录连接到只读 Web 工作台，并补齐不依赖模型密钥的完整工程演示。当前为 alpha 源码候选，尚未创建远端版本标签、发布 npm 包或部署公开站点。

本版本包含：

- 本地只读 HTTP Server 与独立展示协议，查询任务、工作流、报告、事件和 hash 校验后的产物。
- React / TypeScript Web：列表、依赖图、历史 attempt、指标、验证与人工意见、摘要、交接、Skill 和时间线。
- 与真实 API 共用页面的静态录制数据源，12 阶段播放/暂停/调速/跳转/倒退，不回退到真实 API。
- 实际运行固定脚本的全流程：需求确认、故意失败、显式重试、代码与测试检查、补充输入、文档验收、上游返工和再次交付。
- 桌面与移动端真实浏览器截图、回放录屏、讲稿、源码归档与校验文件生成工具。

快速体验：

```bash
npm ci --include=dev
npm run web:demo:build
npm run showcase:serve
# 开发机打开 http://127.0.0.1:4311/
```

自己的工作区继续使用 `npm run web:build` 和 `npm run server -- --workspace <已有目录> --web apps/web/dist`。CLI 入口、环境文件用法和 `.taskweave` v1 数据保持兼容；Web/构建及后端包统一版本 0.5.0-alpha.1，Skill 的自身版本不随包版本改变。

演示验证固定脚本的工程行为，**不宣称真实模型成功率、Token 降幅或实际人工节省**。Token 为 0，Provider 回合计数不是远端 LLM 请求；确认与回答由脚本代行。报告保留失败/返工时间不完整的提示。截图/录屏的浏览器结果见 `docs/media/capture.json`，完整说明见 [Demo 指南](../demo/README.md)。

已知边界：固定 DAG 串行执行、本地单用户、共享文件工作区、无产物历史版本或 Web 执行控制。列表在内存读取后分页，历史规模与累计读取预算需要后续治理。静态录制载荷约 0.8 MB，Demo 构建的数据块较大，真实工作区构建不包含这份载荷。记录和业务文本不提供通用语义脱敏。
